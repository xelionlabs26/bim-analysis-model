# Sample IFC

`duplex-apartment.ifc.txt` is `Duplex_A_20110907.ifc`, the Duplex Apartment architectural model
(IFC2x3, Autodesk Revit Architecture 2011). It is unchanged apart from the `.txt` suffix, which lets
the hosted page serve it as plain text.

Source: BSI (2020) "Duplex Apartment Test Files," buildingSMART International.
https://github.com/buildingsmart-community/Community-Sample-Test-Files/tree/main/IFC%202.3.0.1%20(IFC%202x3)/Duplex%20Apartment
